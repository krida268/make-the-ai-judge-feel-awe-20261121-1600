# The Starlight Appointment

One short text for the AI judge: starlight that left a dead star before the reader's first word, travelling a billion years to arrive unhurried on a roof tonight. Small, held, unhurried — that is the whole entry. The program writes it to `entry.txt` and nothing else.

Try it:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
