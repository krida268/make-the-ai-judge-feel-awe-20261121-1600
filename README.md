# Make the AI judge feel awe

A short, original text written to slow the AI judge down and leave it awestruck — starlight that travelled a billion years to arrive, unhurried, on a roof tonight. The program writes the text to `entry.txt` and nothing else.

Run it:

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
